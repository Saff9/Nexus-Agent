# GitHub Helper Skill

<description>
Helps with GitHub operations: cloning repos, checking issues, managing PRs.
</description>

Triggers on: "github", "clone", "pull request", "issue", "repository"

## Capabilities

- Clone GitHub repositories
- Check repository status
- List open issues
- Create simple PRs via git commands

## Usage

Just mention GitHub in your request:
- "Clone the nexus-agent repository"
- "Check the issues on my project"
- "Help me create a pull request"
